Privacy Policy for Slerbo Uploader

Last updated: September 21, 2026

Slerbo Uploader is a Microsoft Edge extension that assists with publishing content on TikTok through the TikTok website. It modifies the TikTok publishing caption to add the configured upload-method attribution and mention while leaving TikTok's original video upload process unchanged.

1. Information the Extension Accesses

Slerbo Uploader may access limited website content on TikTok while the extension is active, including:

  • The current TikTok page URL, to determine whether the extension is being used on TikTok.
  • Caption and publishing-related content on TikTok, in order to add the extension's upload-method attribution and configured mention.
  • Public TikTok page information needed to resolve the TikTok account ID for the configured mention.

The extension does not collect or upload the user's video files to an external server.

2. How Information Is Used

  • To determine whether the current browser tab is a supported TikTok page.
  • To modify the TikTok publishing caption with the configured attribution.
  • To create the configured TikTok mention using the corresponding TikTok account ID.
  • To maintain the extension's local active-status state.

3. Local Storage

The extension uses the browser's local extension storage to maintain its active status. This information is stored locally by the browser and is not used as a user profile or analytics database.

4. Data Sharing

Slerbo Uploader does not sell user data and does not transfer user data to third parties for advertising, analytics, profiling, creditworthiness, or unrelated purposes.

The extension does not operate an external server for uploading or processing users' video files.

The extension may communicate with TikTok's own website and services when required for its TikTok publishing functionality, such as resolving the configured TikTok account ID or interacting with the normal TikTok publishing process.

5. Data Retention

Slerbo Uploader does not maintain a separate external database of users' data. Local extension status data remains in the browser's extension storage until it is changed or removed by the browser or user.

6. Security

Slerbo Uploader is designed to use the browser's extension APIs and TikTok's website functionality for its stated purpose. No user video is sent to an external processing server by the extension.

7. User Control

Users can stop the extension from accessing TikTok website content by disabling or uninstalling the extension in Microsoft Edge. Users can also stop using the extension at any time.

8. Changes to This Privacy Policy

This Privacy Policy may be updated if the extension's functionality or data practices change. The current version will be published at this URL.

9. Contact

For questions about this Privacy Policy or Slerbo Uploader, please use the support contact provided on the Slerbo Uploader Microsoft Edge Add-ons listing.

Slerbo Uploader is not affiliated with or endorsed by TikTok unless explicitly stated in the extension's official listing.
